# ForeLab

ForeLab is an ongoing HBKU senior design project for portable digital forensics on NVIDIA Jetson hardware. The goal is to run collection, analysis, and AI-assisted incident reporting locally instead of sending evidence to a cloud service.

![ForeLab logo](assets/forelab-logo.jpg)

## Current status

The main hardware and analysis tools are set up. The team is currently developing and validating the automated pipeline; this is not yet a finished product.

## My responsibilities

- Build and connect the automated analysis pipeline.
- Lead the Velociraptor integration in my workstream.
- Develop the AI-assisted report-generation stage.
- Contribute to the physical, 3D-printed prototype.
